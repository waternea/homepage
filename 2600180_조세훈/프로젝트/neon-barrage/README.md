# NEON BARRAGE

웹(HTML5 Canvas)으로 만든 세로 스크롤 탄막 슈팅 프로토타입입니다. 외부 라이브러리 없이 순수 JavaScript로 동작합니다.

## 실행 방법
- `index.html`을 더블클릭하면 바로 실행됩니다. (빌드/설치 불필요)
- 또는 폴더에서 `npx serve` / `python -m http.server` 로 로컬 서버를 띄워도 됩니다.

## 조작
| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| Shift | 저속 이동 (판정점 표시, 정밀 회피) |
| Z / Space | 샷 |
| X | 폭탄 (탄 전체 소거 + 무적, 피격 직후 8프레임 안에 쓰면 데스봄) |
| Esc / P | 일시정지 |
| M | 음소거 |

## 규칙 요약
- 라이프 3, 폭탄 3. 피격하면 폭탄이 3개로 리필됩니다.
- 탄에 아슬아슬하게 스치면 **그레이즈**. 누적될수록 점수 배율이 올라갑니다(최대 x3).
- 스테이지 1: 잡몹 웨이브 → 중간보스(Prism Sentinel) → 후반 웨이브 → 보스(Aurora Core, 4페이즈).
- 스펠카드는 피격/폭탄 없이 깨면 스펠 보너스를 받습니다.

## 파일 구조
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 페이지, 캔버스 스케일링 |
| `patterns.js` | **탄막 패턴 데이터** (잡몹 패턴, 보스 페이즈). 여기만 고치면 패턴 추가/밸런싱 가능 |
| `audio.js` | Web Audio API로 합성하는 효과음 |
| `game.js` | 게임 루프, 플레이어, 적/보스, 탄 풀링, 충돌, 렌더링, 씬 |

## 패턴 추가 방법
`patterns.js`의 `PATTERNS`에 이미터 배열을 추가하고, `game.js`의 `buildStage()`에서 `pattern: '이름'`으로 쓰면 됩니다.
이미터 필드 설명은 `patterns.js` 상단 주석을 참고하세요.
